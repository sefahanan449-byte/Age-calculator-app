# Age Calculator App

A solution to the [Age Calculator App challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/age-calculator-app-dF9DFFpj-Q).

## Features

- Enter day, month and year to see your exact age in years, months and days
- Validation for empty fields, invalid days and months, dates that don't exist, and future dates
- Responsive layout for mobile and desktop
- Hover and focus states on inputs and the submit button
- Count-up animation for the results

## Built with

- HTML5
- Tailwind CSS
- JavaScript
- Vite

## Run it locally

npm install
npm run dev
Then open http://localhost:5173/ in your browser.

## What I learned

- Building a responsive layout with Tailwind utility classes
- Validating form input with JavaScript
- Working with the Date object to calculate age
- Setting up a project with Vite and Tailwind CSS
